# Feature Flag Control Panel

## Overview
The **Feature Flag Control Panel** is a web application designed to provide dynamic control over application features. It allows teams to manage feature flags, enabling or disabling features without requiring code redeployment. This project is built with a .NET backend and an Angular frontend, leveraging Docker for containerization and scalability.

## Features
- **Global and Override Dashboard**: A comprehensive set of dashboards that allows users to view and manage global feature flags, as well as override feature flag states for specific users or groups.
- **Feature Flag Management**: Create, update, and toggle feature flags dynamically.
- **User Authentication**: Secure user authentication with JWT-based token management.
- **Override System**: Enables overriding of feature flag states for specific users.

## Technologies Used
- **Backend**: .NET 6, Entity Framework Core
- **Frontend**: Angular
- **Authentication**: JWT (JSON Web Tokens)
- **Database**: SQL Server
- **Containerization**: Docker
